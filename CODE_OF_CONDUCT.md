# Code of Conduct

Version: 1.0 Draft

---

# Purpose

This project is built around serious engineering, respectful collaboration, scientific integrity, and long-term thinking.

---

# Expected Behavior

Contributors should:

- communicate respectfully
- focus on evidence
- challenge ideas constructively
- preserve technical integrity
- avoid personal attacks
- respect confidentiality
- protect intellectual property
- document decisions clearly

---

# Unacceptable Behavior

Unacceptable behavior includes:

- harassment
- discrimination
- abusive communication
- leaking confidential information
- intentionally misleading documentation
- committing sensitive data
- ignoring security rules

---

# Collaboration Principle

Truth before convenience.

Architecture before ego.

Long-term capability before short-term speed.
