# ADR-0004 Domain-First Architecture

Status: Accepted

---

# Context

SmartCoat is an Enterprise Intelligence Infrastructure specialized for Advanced Materials industries.

To avoid technology-driven architecture, the system must be derived from domain concepts.

---

# Decision

SmartCoat shall use Domain-First Architecture.

Domain concepts, boundaries, ubiquitous language, and domain capabilities must be defined before implementation architecture.

---

# Consequences

- Databases derive from domain objects.
- APIs use domain language.
- Agents operate within domain boundaries.
- AI models must respect domain meaning.
- Knowledge Graph design derives from domain ontology.
