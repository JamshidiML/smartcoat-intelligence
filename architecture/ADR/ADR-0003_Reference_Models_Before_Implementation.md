# ADR-0003 Reference Models Before Implementation

Status: Accepted

---

# Context

SmartCoat is a complex Enterprise Intelligence Architecture.

Without stable reference models, business, knowledge, AI, agent, and platform components may evolve inconsistently.

---

# Decision

All future architecture shall be derived from approved Reference Models before implementation.

---

# Consequences

- Business Architecture must reference RM-01 to RM-07.
- AI Architecture must not redefine core concepts.
- Agent workflows must use canonical enterprise language.
- Data models must derive from ontology and object models.
