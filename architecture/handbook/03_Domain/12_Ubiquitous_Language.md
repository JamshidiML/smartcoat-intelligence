# Purpose

This chapter defines the domain language for SmartCoat.

The language follows Domain-Driven Design principles and must remain aligned with the Enterprise Language.

---

# Language Rule

One concept shall have one name.

One name shall have one meaning.

Domain language must never conflict with Enterprise Language.

---

# Core Domain Terms

- Material
- Formulation
- Fabric
- Supplier
- Customer
- Project
- Experiment
- Batch
- Quality Test
- Defect
- Failure
- Regulation
- Requirement
- Decision
- Evidence
- Lesson Learned
- Risk
- Opportunity
- Capability

---

# Domain Language Governance

New domain terms require:

- Definition
- Domain owner
- Relationship mapping
- Ontology alignment
- ADR if architecturally significant

---

# Ubiquitous Language Rule

All SmartCoat software, APIs, agents, databases, knowledge graphs, and documentation shall use the approved ubiquitous language.
