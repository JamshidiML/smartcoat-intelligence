Version: 1.0

Status: Draft

---

# Purpose

This chapter defines Identity and Access Management.

IAM controls who can access SmartCoat knowledge, tools, agents, APIs, decisions, and enterprise objects.

---

# Identity Types

- Human User
- AI Agent
- Service Account
- Integration Connector
- External Partner
- Customer User
- Supplier User
- Administrator

---

# Access Control Models

SmartCoat may use:

- Role-Based Access Control
- Attribute-Based Access Control
- Object-Level Permissions
- Domain-Based Permissions
- Knowledge Classification Permissions
- Approval-Based Access
- Temporary Access Grants

---

# IAM Rule

AI agents must follow the same or stricter access control rules as human users.
