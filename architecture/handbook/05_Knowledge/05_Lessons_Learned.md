# Purpose

This chapter defines Lessons Learned within SmartCoat.

Lessons Learned are reusable knowledge objects created from experience, outcomes, failures, successes, and decisions.

---

# Definition

A Lesson Learned is a structured knowledge object that captures what the organization should remember and apply in the future.

---

# Lesson Learned Structure

A Lesson Learned should include:

- lesson_id
- title
- domain
- related project
- related objects
- problem
- context
- evidence
- decision
- outcome
- root cause
- recommendation
- confidence
- owner
- validation status
- reuse cases

---

# Lesson Sources

Lessons Learned may come from:

- failed experiments
- successful projects
- quality investigations
- supplier disruptions
- production deviations
- customer complaints
- regulatory changes
- cost overruns
- process improvements

---

# Lesson Rule

A lesson is valid only if it can influence future decisions.
