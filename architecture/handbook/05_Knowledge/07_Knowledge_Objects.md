# Purpose

This chapter defines Knowledge Objects.

Knowledge Objects are structured units of enterprise knowledge that can be stored, connected, searched, validated, reused, and evolved.

---

# Knowledge Object Types

- Observation
- Evidence
- Hypothesis
- Finding
- Lesson Learned
- Engineering Rule
- Business Rule
- Scientific Rule
- Constraint
- Assumption
- Trade-off
- Failure Mode
- Root Cause
- Recommendation
- Insight
- Prediction
- Decision Rationale

---

# Knowledge Object Structure

Every Knowledge Object should include:

- object_id
- object_type
- title
- description
- domain
- related entities
- evidence
- provenance
- confidence
- owner
- validation status
- lifecycle state
- related decisions
- related events
- created_at
- updated_at

---

# Knowledge Object Rule

Knowledge that cannot be connected, validated, or reused should not be treated as mature enterprise knowledge.
