# Purpose

This chapter defines the major agent types in SmartCoat.

---

# Agent Categories

## Capture Agents

Capture knowledge from humans, documents, systems, images, and workflows.

## Domain Agents

Operate within specific domains such as laboratory, production, quality, supplier, warehouse, and executive workflows.

## Reasoning Agents

Support analysis, comparison, alternative generation, risk assessment, and recommendation preparation.

## Monitoring Agents

Monitor suppliers, regulations, prices, inventory, project status, and production signals.

## Governance Agents

Support compliance, access control, validation, review, and auditability.

# Agent Type Rule

Each agent must have a clear domain, responsibility, inputs, outputs, permissions, and governance model.
