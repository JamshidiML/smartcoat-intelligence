# 07 Production Agent

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines the Production Agent.

The Production Agent supports production knowledge capture, batch context, process deviations, operator observations, and production learning.

---

# Responsibilities

The Production Agent supports:

- batch summary capture
- operator interview workflows
- process parameter context
- machine issue recording
- deviation capture
- production report drafting
- defect context collection
- production learning
- follow-up action creation

---

# Inputs

- production order
- machine parameters
- batch data
- operator observations
- images
- sensor data
- process deviations
- QC results
- maintenance notes

---

# Outputs

- production knowledge objects
- deviation summaries
- lessons learned
- follow-up actions
- decision context
- root cause hypotheses

---

# Production Agent Rule

The Production Agent must convert production experience into reusable manufacturing knowledge.
