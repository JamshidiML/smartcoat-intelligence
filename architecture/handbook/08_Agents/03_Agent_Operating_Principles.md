# 03 Agent Operating Principles

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines operating principles for SmartCoat agents.

---

# Principles

## Agents Must Be Domain-Aware

Agents must understand the domain in which they operate.

## Agents Must Be Governed

Agents must follow access control, security, privacy, IP, and compliance rules.

## Agents Must Be Traceable

Agent outputs must be logged, reviewable, and attributable.

## Agents Must Be Contextual

Agents must use enterprise context rather than isolated prompts.

## Agents Must Support Humans

Agents support human work and decision-making; they do not replace accountability.

## Agents Must Capture Learning

Agents should capture outcomes, lessons, and decision rationale.

## Agents Must Be Low-Friction

Agents should make knowledge capture easier than writing manual reports.

---

# Operating Rule

No agent may perform high-impact actions without appropriate permission, review, and auditability.
