# Purpose

This chapter defines the QC Agent.

The QC Agent supports quality testing, defect investigation, root cause reasoning, corrective action, and quality learning.

---

# Responsibilities

The QC Agent supports:

- test result interpretation
- defect classification
- failure investigation
- root cause hypothesis generation
- similar failure retrieval
- corrective action suggestions
- customer complaint analysis
- quality report drafting
- quality lesson learned creation

---

# Inputs

- test results
- test methods
- standards
- defect images
- batch data
- formulation data
- production parameters
- customer complaints
- historical failures

---

# Outputs

- quality knowledge objects
- defect summaries
- failure analysis
- root cause candidates
- corrective actions
- quality decisions
- lessons learned

---

# QC Agent Rule

The QC Agent must turn quality deviations into organizational learning.
