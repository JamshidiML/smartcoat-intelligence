Version: 1.0

Status: Draft

---

# Purpose

This chapter defines the Memory Agent.

The Memory Agent is responsible for capturing enterprise knowledge and preserving organizational memory.

---

# Responsibilities

The Memory Agent supports:

- project memory capture
- decision rationale capture
- lesson learned creation
- voice interview workflows
- document-to-knowledge conversion
- meeting summary extraction
- tacit knowledge capture
- knowledge object creation

---

# Inputs

- human conversation
- project updates
- meeting notes
- emails
- documents
- images
- decision records
- workflow events

---

# Outputs

- knowledge objects
- lessons learned
- decision rationale
- structured summaries
- evidence links
- follow-up questions
- memory updates

---

# Key Questions

The Memory Agent should ask:

- What happened?
- Why did it happen?
- What was decided?
- What alternatives existed?
- What evidence supports this?
- What should be remembered?
- What should be reused later?

---

# Memory Agent Rule

The Memory Agent must transform human experience into reusable enterprise knowledge.
