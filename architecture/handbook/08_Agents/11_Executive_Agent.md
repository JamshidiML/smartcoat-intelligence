Version: 1.0

Status: Draft

---

# Purpose

This chapter defines the Executive Agent.

The Executive Agent supports leadership visibility, strategic decision preparation, cross-domain context, risk awareness, and enterprise learning summaries.

---

# Responsibilities

The Executive Agent supports:

- executive summaries
- strategic risk overview
- project portfolio insights
- decision preparation
- cross-domain knowledge retrieval
- capability progress reports
- supplier risk summary
- quality trend summary
- innovation pipeline overview

---

# Inputs

- project data
- decision data
- quality data
- production data
- supplier data
- financial context
- market intelligence
- regulatory updates
- organizational learning metrics

---

# Outputs

- executive briefings
- strategic decision context
- risk summaries
- opportunity summaries
- portfolio recommendations
- organizational learning insights

---

# Executive Agent Rule

The Executive Agent must support strategic understanding without hiding uncertainty, risk, or missing context.
