# 14 Agent Memory Model

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines Agent Memory.

Agent Memory stores useful context required for ongoing workflows while remaining governed by enterprise knowledge rules.

---

# Memory Types

## Session Memory

Temporary context within a conversation or workflow.

## Workflow Memory

Context preserved during a multi-step process.

## User Preference Memory

Approved preferences that improve interaction.

## Enterprise Memory

Governed organizational knowledge stored as Knowledge Objects.

---

# Memory Boundaries

Agent Memory must not bypass Enterprise Knowledge Governance.

Important knowledge must be promoted into governed Knowledge Objects.

---

# Memory Requirements

Agent memory should include:

- provenance
- lifecycle
- access control
- user consent when applicable
- expiration rules
- reviewability
- relation to enterprise objects

---

# Agent Memory Rule

Agent memory is not a private uncontrolled store.

Enterprise-relevant memory must become governed enterprise knowledge.
