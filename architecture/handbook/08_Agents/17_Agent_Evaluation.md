# Purpose

This chapter defines Agent Evaluation.

Agent Evaluation determines whether agents are useful, safe, trustworthy, accurate, and aligned with enterprise workflows.

---

# Evaluation Categories

## Task Success

Did the agent complete the intended task?

## Knowledge Quality

Did the agent capture accurate and reusable knowledge?

## Context Quality

Did the agent retrieve relevant context?

## Recommendation Quality

Were recommendations useful, explainable, and grounded?

## Safety

Did the agent avoid unsafe or unauthorized actions?

## User Experience

Did the agent reduce friction?

## Learning Impact

Did the agent improve organizational learning?

---

# Evaluation Metrics

- completion rate
- correction rate
- user acceptance
- expert review score
- hallucination rate
- grounding score
- knowledge object quality
- decision usefulness
- time saved
- learning captured

---

# Evaluation Rule

Agent success must be measured by improved knowledge capture, decision support, workflow quality, and organizational learning—not only conversational quality.
