# Purpose

This chapter defines the Agent Architecture of SmartCoat.

Agents are specialized enterprise intelligence components that interact with humans, systems, documents, knowledge graphs, workflows, and decisions.

---

# Core Thesis

Agents are not general chatbots.

Agents are governed, domain-aware, context-aware, task-oriented enterprise intelligence workers.

They operate inside the SmartCoat architecture to support:

- knowledge capture
- context retrieval
- workflow assistance
- decision preparation
- evidence collection
- recommendation explanation
- learning capture
- enterprise memory

# Agent Rule

Every agent must operate within enterprise governance, ontology, access control, decision governance, and human accountability.
