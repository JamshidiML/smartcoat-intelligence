# 09 Supplier Agent

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines the Supplier Agent.

The Supplier Agent supports supplier intelligence, material availability, pricing, lead time, risk, substitution, and supplier communication.

---

# Responsibilities

The Supplier Agent supports:

- supplier information capture
- price monitoring
- lead time monitoring
- MOQ tracking
- capacity tracking
- availability updates
- supplier risk alerts
- substitution candidate search
- supplier communication summaries
- sourcing decision support

---

# Inputs

- supplier emails
- supplier portals
- price lists
- TDS
- SDS
- availability updates
- logistics data
- market signals
- regulatory constraints
- material requirements

---

# Outputs

- supplier knowledge objects
- material availability updates
- price intelligence
- lead time estimates
- risk alerts
- substitution recommendations
- sourcing decision context

---

# Supplier Agent Rule

The Supplier Agent must connect technical material suitability with price, availability, logistics, and risk.
