# Purpose

This chapter defines the Lab Agent.

The Lab Agent supports R&D, formulation, experimentation, sample preparation, test planning, and laboratory knowledge capture.

---

# Responsibilities

The Lab Agent supports:

- experiment planning
- formulation history retrieval
- similar project search
- hypothesis capture
- sample tracking
- test result interpretation
- failure capture
- lesson learned generation
- lab report drafting
- decision rationale capture

---

# Inputs

- formulation data
- material data
- experiment notes
- lab results
- images
- customer requirements
- historical projects
- test standards
- scientist interviews

---

# Outputs

- experiment knowledge objects
- formulation reasoning
- test summaries
- failure analysis
- project memory
- recommendations
- lessons learned

---

# Lab Agent Rule

The Lab Agent must preserve the reasoning behind experiments, not only the results.
