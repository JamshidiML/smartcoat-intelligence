# AI Capability Categories

## Knowledge AI

- document extraction
- voice transcription
- semantic classification
- knowledge object creation
- lesson learned extraction
- ontology mapping

## Context AI

- relationship discovery
- similarity detection
- graph enrichment
- contextual retrieval
- dependency mapping

## Reasoning AI

- trade-off analysis
- alternative generation
- root cause reasoning
- constraint checking
- risk reasoning

## Prediction AI

- quality prediction
- failure prediction
- lead time prediction
- cost prediction
- demand prediction
- material risk prediction

## Recommendation AI

- material recommendation
- supplier recommendation
- formulation recommendation
- process recommendation
- quality action recommendation
- project prioritization

## Vision AI

- defect detection
- defect segmentation
- fabric inspection
- coating inspection
- image classification
- anomaly detection

# Capability Rule

Every AI capability must map to a business capability, domain capability, knowledge object, decision object, or organizational capability.
