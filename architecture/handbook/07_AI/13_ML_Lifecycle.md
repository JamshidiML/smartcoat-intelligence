# Requirements

Every ML project should define:

- business problem
- decision target
- data sources
- labels
- features
- evaluation metric
- baseline
- validation method
- risks
- limitations
- monitoring plan
- owner

---

# ML Rule

No ML model should be deployed without a defined decision use case, evaluation metric, and monitoring plan.
