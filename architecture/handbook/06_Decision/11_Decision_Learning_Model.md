# Purpose

This chapter defines how decisions create learning.

Decision Learning is the process by which outcomes improve future decisions.

---

# Learning Cycle

Decision

↓

Execution

↓

Outcome

↓

Experience

↓

Lesson Learned

↓

Knowledge Update

↓

Future Decision Improvement

---

# Learning Questions

After each significant decision, SmartCoat should ask:

- What happened?
- Was the outcome expected?
- Which assumptions were correct?
- Which assumptions were wrong?
- What evidence was missing?
- Which risks occurred?
- What should be reused?
- What should be avoided next time?
- How should confidence change?

---

# Learning Rule

No high-impact decision is complete until learning has been captured.
