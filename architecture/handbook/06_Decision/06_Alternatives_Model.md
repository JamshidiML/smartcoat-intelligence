# 06 Alternatives Model

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines the Alternatives Model.

Alternatives represent feasible courses of action before a decision is made.

---

# Alternative Definition

An Alternative is a possible action that can be evaluated against objectives, constraints, risks, costs, and expected outcomes.

---

# Alternative Examples

- Use Material A
- Substitute Material B
- Delay production
- Change supplier
- Modify formulation
- Repeat test
- Reject batch
- Accept with deviation
- Escalate to customer
- Run pilot trial
- Update process parameter

---

# Alternative Attributes

Each Alternative should include:

- alternative_id
- description
- expected_benefit
- expected_cost
- risks
- constraints
- required_evidence
- assumptions
- feasibility
- confidence
- affected_objects
- expected_outcome

---

# Alternative Rule

High-impact decisions should evaluate multiple alternatives unless documented constraints justify a single option.
