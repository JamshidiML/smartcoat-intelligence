# 07 Recommendation Model

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines recommendations within SmartCoat.

A recommendation is not a decision.

It is a suggested course of action generated through reasoning.

---

# Recommendation Structure

Every recommendation should include:

- recommendation_id
- related_decision
- recommended_alternative
- rationale
- evidence
- assumptions
- risks
- confidence
- expected_impact
- constraints
- alternatives_considered
- explanation
- reviewer
- status

---

# Recommendation Types

- Material recommendation
- Supplier recommendation
- Formulation recommendation
- Production recommendation
- Quality recommendation
- Procurement recommendation
- Regulatory recommendation
- Strategic recommendation

---

# Recommendation Principle

A recommendation must be explainable.

A recommendation without rationale is not decision intelligence.

---

# Recommendation Rule

Recommendations must never be presented as decisions unless approved by the responsible decision owner.
