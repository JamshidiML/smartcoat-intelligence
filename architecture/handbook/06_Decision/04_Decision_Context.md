Version: 1.0

Status: Draft

---

# Purpose

This chapter defines Decision Context.

Decision Context is the set of relationships, constraints, historical knowledge, business conditions, risks, and objectives required to understand a decision.

---

# Context Components

Decision Context may include:

- materials
- formulations
- suppliers
- customers
- production capability
- quality history
- test results
- regulations
- prices
- logistics
- inventory
- market conditions
- previous decisions
- historical failures
- lessons learned
- current objectives
- risks
- constraints

---

# Context Principle

A decision without context is unreliable.

A recommendation without context is not trustworthy.

---

# Context Retrieval

Decision Context should be retrieved from:

- Knowledge Graph
- Enterprise Information Model
- Domain Architecture
- Event history
- Knowledge Objects
- Reference Models
- External knowledge sources

---

# Decision Context Rule

Every recommendation must explicitly state which context was considered and which context was unavailable.
