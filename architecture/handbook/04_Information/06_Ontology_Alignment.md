# 06 Ontology Alignment

Version: 1.0

Status: Draft

---

# Purpose

This chapter defines how Information Architecture aligns with Enterprise Ontology.

---

# Principle

Ontology defines meaning.

Information Architecture represents meaning.

Therefore, every information object must align with the Enterprise Ontology.

---

# Alignment Requirements

Each information object must specify:

- ontology concept
- canonical definition
- domain owner
- entity type
- relationship types
- allowed lifecycle states
- provenance requirements
- governance rules

---

# Ontology Alignment Rule

No database table, API schema, event, agent memory object, or AI data structure may introduce a new enterprise concept without ontology alignment.
