# Purpose

This chapter defines the role of taxonomy in SmartCoat.

Taxonomy provides classification structures for enterprise objects.

---

# Taxonomy vs Ontology

Taxonomy classifies objects.

Ontology defines meaning and relationships.

Both are required.

---

# Initial Taxonomy Areas

- Material families
- Formulation types
- Fabric types
- Supplier categories
- Customer industries
- Test methods
- Failure modes
- Defect types
- Regulation categories
- Decision types
- Risk categories
- Knowledge object types

---

# Taxonomy Rule

Taxonomies must remain aligned with ontology definitions and canonical enterprise language.
