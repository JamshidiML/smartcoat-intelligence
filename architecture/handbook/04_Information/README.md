Version: 1.0 Draft

# Purpose

This volume defines the Information Architecture of SmartCoat.

It explains how enterprise knowledge is represented as information structures that can be stored, searched, connected, governed, reasoned over, and used for decision intelligence.

# Information Principle

Information Architecture is not only about data storage.

It is about preserving meaning, context, provenance, relationships, and decision usefulness.
