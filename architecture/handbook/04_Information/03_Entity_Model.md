# Purpose

This chapter defines the Enterprise Entity Model.

Entities represent the primary objects that exist inside the SmartCoat enterprise universe.

---

# Entity Definition

An entity is a uniquely identifiable enterprise object with a defined type, lifecycle, owner, relationships, events, and semantic meaning.

---

# Entity Rule

Every entity must have identity, meaning, provenance, lifecycle, and relationships.
