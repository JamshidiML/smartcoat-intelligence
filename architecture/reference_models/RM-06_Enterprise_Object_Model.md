# Purpose

This reference model defines the main object categories inside the SmartCoat enterprise universe.

---

- Customer
- Supplier

---

# Object Rule

Every SmartCoat object must have:

- Identity
- Type
- Owner
- Lifecycle
- Relationships
- Provenance
- Events
