# ADR Coverage Checklist

Version: 1.0

Status: Draft

---

# Purpose

This checklist verifies that major architecture decisions are recorded as ADRs.

---

# Required ADR Areas

- Knowledge-first architecture
- Canonical enterprise language
- Reference models before implementation
- Domain-first architecture
- Canonical information model
- Knowledge graph as context backbone
- Decisions as primary value output
- AI as enterprise intelligence capability
- Agents as governed enterprise workers
- Platform as enterprise intelligence infrastructure
- Deployment as trust infrastructure
- Architecture repository governance
- Root repository documentation as project entry point
- Architecture consistency before implementation

---

# ADR Rule

If a decision changes the direction of architecture, it requires an ADR.
