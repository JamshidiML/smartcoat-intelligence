# 05 Template Governance

Version: 1.0

Status: Draft

---

# Purpose

This document defines governance for architecture templates.

---

# Template Philosophy

Templates reduce inconsistency.

They ensure that future architecture artifacts follow common structure, terminology, and quality expectations.

---

# Template Categories

- Business capability templates
- Domain model templates
- Entity templates
- Relationship templates
- Event templates
- Knowledge object templates
- Decision templates
- AI capability templates
- Agent templates
- Service templates
- API templates
- Deployment templates
- Incident templates

---

# Template Rule

New architecture artifacts should use approved templates unless a documented reason exists.
