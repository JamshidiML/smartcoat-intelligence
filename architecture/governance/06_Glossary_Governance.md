# 06 Glossary Governance

Version: 1.0

Status: Draft

---

# Purpose

This document defines governance for the SmartCoat glossary.

---

# Glossary Philosophy

A shared language is a prerequisite for Enterprise Intelligence.

The glossary protects semantic consistency across architecture, software, AI, agents, and documentation.

---

# Glossary Entry Requirements

Each glossary entry should include:

- canonical term
- definition
- related concepts
- forbidden synonyms, when relevant
- source document
- governance notes, when relevant

---

# Reserved Terms

Reserved terms must not be redefined locally.

Examples:

- Enterprise Knowledge
- Enterprise Context
- Enterprise Intelligence
- Enterprise Decision
- Organizational Capability
- Learning Enterprise
- Knowledge Object
- Decision Object
- Evidence
- Provenance
- Context
- Reasoning
- Recommendation

---

# Glossary Rule

Ambiguous terminology is an architecture defect.
