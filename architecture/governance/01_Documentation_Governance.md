# Purpose

This document defines how SmartCoat architecture documentation is created, reviewed, maintained, versioned, and governed.

---

# Documentation Philosophy

SmartCoat documentation is not passive description.

It is an architecture asset.

It defines how the SmartCoat Enterprise Intelligence Architecture should be understood, implemented, reviewed, and evolved.

---

# Document Categories

## Foundation Documents

Define philosophy, identity, principles, constitution, theory, and language.

## Reference Models

Define stable conceptual contracts.

## Architecture Volumes

Define business, domain, information, knowledge, decision, AI, agent, platform, deployment, and future architecture.

## ADRs

Explain why major architecture decisions were made.

## Diagrams

Visualize architecture models and flows.

## Templates

Standardize future architecture artifacts.

## Glossary

Defines canonical terms.

## Governance Documents

Define how the repository evolves.

# Documentation Rule

Every document must have purpose, status, version, and clear ownership or governance responsibility.
