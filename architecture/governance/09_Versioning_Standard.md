# 09 Versioning Standard

Version: 1.0

Status: Draft

---

# Purpose

This document defines versioning standards for SmartCoat architecture artifacts.

---

# Version Types

## Release Version

Used for architecture release packages.

Example:

`Release 1.1`

## Document Version

Used inside individual documents.

Example:

`Version: 1.0`

## ADR Number

Used for architecture decisions.

Example:

`ADR-0012`

---

# Status Values

Documents may use:

- Draft
- Reviewed
- Approved
- Deprecated
- Superseded

---

# Versioning Rule

Document versions should change when meaning changes, not for every typo or formatting correction.
