Version: 1.0

---

# Purpose

This document defines the architecture review workflow for SmartCoat.

---

# Review Types

## Terminology Review

Checks canonical language consistency.

## Architecture Consistency Review

Checks alignment across volumes and reference models.

## Technical Review

Checks technical feasibility.

## Security Review

Checks access, confidentiality, privacy, and IP protection.

## Governance Review

Checks ownership, lifecycle, status, and maintenance responsibility.

## Release Review

Checks completeness before commit and push.

---

# Review Workflow

Draft

↓

Self Review

↓

Architecture Review

↓

Terminology Review

↓

Security or Governance Review, when needed

↓

Approved

↓

Release

---

# Review Rule

A document should not become Approved until terminology, architecture consistency, and governance alignment have been reviewed.
