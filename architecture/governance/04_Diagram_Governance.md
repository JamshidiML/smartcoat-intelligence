# 04 Diagram Governance

Version: 1.0

Status: Draft

---

# Purpose

This document defines governance for SmartCoat architecture diagrams.

---

# Diagram Philosophy

A diagram must explain one architectural idea clearly.

Decorative diagrams are not architecture diagrams.

---

# Diagram Types

- Reference model diagrams
- Business architecture diagrams
- Domain diagrams
- Information model diagrams
- Knowledge architecture diagrams
- Decision flow diagrams
- AI architecture diagrams
- Agent orchestration diagrams
- Platform diagrams
- Deployment diagrams
- Governance diagrams

---

# Diagram Format

Mermaid is the default diagram format for architecture diagrams.

Diagrams should be stored as `.mmd` files.

---

# Diagram Requirements

Each diagram should have:

- clear title
- defined purpose
- simple structure
- readable labels
- related document reference
- version if important

---

# Diagram Rule

If a diagram cannot be understood without long explanation, it is too complex.
