# Consistency Checklist

Version: 1.0 Draft

---

# Purpose

This checklist supports repository-wide consistency review.

---

# Structure

- architecture portal exists
- handbook volumes exist
- reference models exist
- ADR index exists
- release index exists
- diagram index exists
- template index exists
- governance index exists
- glossary exists

---

# Naming

- folder names are consistent
- file names are descriptive
- release names match changelog
- ADR numbers are not duplicated

---

# Terminology

- canonical terms are used
- deprecated terms are documented
- glossary aligns with Foundation
- Enterprise Language is respected

---

# Traceability

- major architecture decisions have ADRs
- releases have release records
- diagrams are indexed
- templates are indexed
- root docs link to architecture portal

---

# Implementation Readiness

- .gitignore protects data and secrets
- first implementation scope is defined
- architecture quality gate exists
- governance process exists
