# Pilot Use-Case Portfolio

Status: Prioritized discovery backlog; only UC-01 is the first demonstrator

## Prioritization Method

Prioritize measurable user pain, learning-loop coverage, approved-data
feasibility, current roadmap fit, human reversibility, and reuse of platform
capabilities. A high value score never bypasses governance or technical gates.

## UC-01 Acceptance Contract

UC-01 is complete only when a pilot user can, without developer intervention:

1. frame one approved generalized requirement
2. retrieve and judge reviewed prior lessons with evidence
3. identify material missing information
4. capture one new experiment/observation/failure through a usable interface
5. correct and approve a structured draft
6. persist and retrieve it under the same organization boundary
7. distinguish fact, observation, result, hypothesis, and recommendation
8. expose provenance, status, uncertainty, corrections, and audit events
9. record baseline/assisted time, quality, relevance, trust, and reuse evidence

Any failed security, permission, tenant, deletion, or human-approval control blocks
live use regardless of product acceptance.

## Explicit Non-Claims

The portfolio does not promise automatic formulation, supplier choice, root
cause, compliance, product release, production optimization, machine control, or
business execution. These are human decisions and separate future product cases.
